# 系统与模型兼容表

第一次使用优先选择 **Windows 11 x64 + QCE 6.3.0 + 本地 Laya / CPU**。

「本机已验证」指开发机上实际运行过；不代表所有同类电脑都通过。跨机正在试用，新的结果会按实际环境补充。暂无经过跨机验证的最低内存、处理速度或所有显卡保证。

## 电脑与显示

| 环境 | 当前情况 | 使用建议 |
| --- | --- | --- |
| Windows 11 x64 | 实际 ZIP 在开发机上已检查启动与首次设置，跨机正在测试 | 当前优先路线 |
| Windows 10 x64 | 尚未验证 | 可按清单记录实际结果，不当作已支持的验收结论 |
| Windows ARM / macOS / Linux | 当前没有程序包 | 本次提供 Windows x64 下载 |
| 单显示器，系统缩放 125% / 150% / 200% | 开发机已实测 | 控件异常时记录实际缩放比例 |
| 两个或更多显示器、跨屏拖动 | 尚未验证 | 有设备的人可补充试用，没有设备无需测试 |
| 另一台电脑或另一个 Windows 账号 | 正在开展试用，尚无完整通过结果 | 先按[首次设置](SETUP.md)操作，凭证需要重新配置 |

## QQ 连接

| 环境 | 当前情况 | 使用建议 |
| --- | --- | --- |
| QQ + QCE 6.3.0 | 开发机有限单聊和指定群聊已有实测 | 用自己的 QQ 登录，保持 QCE 运行，先试一个会话 |
| QCE 6.3.0 一键安装包在新电脑上安装、自动发现 | 固定安装说明已核对，非开发者跨机使用仍在验证 | 跟着[设置说明](SETUP.md)操作，失败记录具体一步 |
| 其他 QQ 或 QCE 版本 | 未逐一验证 | 不把一个版本的结果泛化，未知版本按页面提示小范围试用 |
| 字段或结构不兼容的 QCE | 已有合成检查，真实未知环境仍待验证 | 结构不兼容时停止在线写入，保留本地记录并反馈 |
| QCE standalone 离线浏览模式 | 可以用于相应离线浏览，不提供在线新消息 | 持续同步应采用已登录的在线路线 |

QQVibe 不会自动升级或替换你的 QQ/QCE。更新这些程序后，请先核对身份、版本和读取范围。

## 模型与分析

| 路线 | 当前情况 | 使用建议 |
| --- | --- | --- |
| 本地 Laya / CPU | 固定实际模型在开发机上已运行，包内模型与首次设置已检查 | 第一次使用优先选择，语义与画像仍需人工判断 |
| 本地 Laya / GPU（WebGPU） | 开发机 Intel UHD 已实测 | 出错切回 CPU，这条路线不是 CUDA |
| NVIDIA / AMD、多显卡、其他驱动 | 尚未验证 | 不承诺所有显卡可加速，可提供型号与错误提示 |
| Anthropic、Responses、Chat Completions、Gemini、Ollama 协议入口 | 对本机假服务的流程已检查 | 只证明界面与请求流程，不算真实服务通过 |
| 真实云端 API | 尚未完成验证 | 自己配置服务时确认权限与预算，结果单独记录 |
| 真实本地 Ollama | 尚未完成验证 | 先准备自己的服务与模型，不能拿假服务结果替代 |
| 单聊与群聊标签、人物画像的完整质量 | 尚未完成审阅 | 群标签是实验候选，分数非准确率，画像非事实 |

API/Ollama 功能保留在应用中，具体服务、模型和硬件只有实际使用后才加入已验证范围。[已知问题](KNOWN-ISSUES.md) · [试用清单](R9-TRIAL.md)
