# 问题反馈模板

反馈渠道：[GitHub Issues](https://github.com/xzyj50609/QQVibe/issues)；内部试用先发给交付者。不要提交聊天正文、QQ 号码、token、Key、数据库、完整备份或私人截图。设置可导出匿名诊断，提交前自行打开检查；截图遮盖身份与正文。

- 包文件名 / ZIP SHA256 / 应用版本 / candidate：
- 系统版本、位数、RAM、显卡及驱动、缩放、显示器数量：
- QQ/QCE 版本（未知写未知）：
- 模型路线与模型名 / 实际 provider（不得填写密钥）：
- 新目录首跑或升级、是否 API-only：
- 步骤（尽量用合成文字复现）：
- 预期 / 实际结果 / 错误提示：
- 发生时间、是否稳定重现、关闭重开是否恢复：
- 受影响范围、已尝试措施、匿名诊断附件：
- 是否有费用或数据损失（只写可确认事实）：

语义反馈区分错归作者/引用、标签不合理、样本不足；给获准且脱敏的短例，不上传整段真实聊天。疑似账号或成员串数据应停止继续分析并保留现场。
