# 句豆 · ChatBean 问题反馈

你可以把下面的模板直接发给提供软件的同学，不需要注册或学会使用 GitHub。熟悉 GitHub 的人也可以在 [Issues](https://github.com/xzyj50609/QQVibe/issues)提交。

**只收集版本、失败步骤和匿名诊断，不要求上传聊天或凭证。** 不要发送 QQ 号码、群号、密码、token、API Key、数据库、完整备份或未遮盖的私人截图。

## 简短模板

复制后填写，不知道的项目写「未知」：

```text
QQVibe 版本：
下载的 ZIP 文件名：
Windows 版本：
QCE 版本：
模型选择（如本地 Laya / CPU）：

我在做什么：
失败在第几步：
我原本希望看到：
实际看到：
错误提示（原样抄文字，去掉账号和凭证）：
关闭重新打开后：恢复 / 仍有问题 / 没试

是否附匿名诊断：是 / 否
是否发现数据丢失或身份归属错误：是 / 否 / 不确定
```

## 导出匿名诊断

1. 打开 QQVibe 的设置，进入 **「关于 QQVibe」**。
2. 点 **「导出诊断信息」**，保存文件。
3. 自己打开文件检查后再发送。

诊断用于查看版本、运行状态和计数，不应包含聊天正文、账号标识或密钥。不要用数据库、完整日志目录或备份代替匿名诊断。

## 需要时再补充

- 如果是显示问题：显示器数量、Windows 缩放比例。
- 如果是 GPU 问题：显卡型号、驱动版本；切换 CPU 后是否恢复。
- 如果是连接问题：QCE 安装方式、是否已登录、是否用自定义目录或端口；不要贴 token。
- 如果是 API/Ollama 问题：服务名、模型名、接口协议、服务版本；不要贴 Key。
- 如果是结果不合理：记录「标签判断不符」「引用归错作者」「画像对象混淆」等问题类型。尽量用自己编的一小段示例复现，不贴真实聊天。
- 如果愿意：补充问题发生时间、能否重复、已经试过的处理方法，以及[试用清单](R9-TRIAL.md)中的失败序号。

启动失败、数据丢失或账号/成员串数据需要优先处理。遇到这些情况先停止继续分析，保留原程序目录与提示，不要删除数据或反复覆盖安装。
