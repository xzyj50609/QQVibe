# 已知问题与处理方法

以下是当前版本的使用限制和常见卡点。它们不会被写成已经解决；其他电脑的实际结果会继续补充。完整环境状态见[兼容表](COMPATIBILITY.md)。

## 常见卡点

| 看到的情况 | 先这样处理 | 当前边界 |
| --- | --- | --- |
| Windows 提示来源未知或拦截运行 | 确认来自本仓库下载页，可用下载页的 SHA256 校验 ZIP；不确定时保留提示并反馈 | 程序尚未签名，不能靠关闭安全软件作为通用解决办法 |
| 点开 ZIP 后找不到程序，或打开不完整 | 先「全部解压缩」，再打开 win-unpacked 中的 QQVibe.exe | 源码 ZIP 不能当作程序运行；程序需要整套解压文件 |
| 提示没有模型 | 完整包核对是否完整解压；标准包点「下载模型」或「选择目录」 | 缺模型时本地分析暂不可用，界面与 API 设置仍可使用 |
| 模型下载慢或失败 | 保留错误提示，重试或按[手动模型步骤](SETUP.md)准备固定版本 | 不同网络能否访问 GitHub/Hugging Face 仍受实际网络影响 |
| QCE 没有连接成功 | 先确认 QCE 运行并已登录自己的 QQ，再点「连接本机 QQ / QCE」 | 6.3.0 为当前固定试用版本，另一电脑的安装和自动发现仍在测试 |
| 群标签看起来不合理 | 回看原消息及上下文，把问题类型记录在反馈中 | 引用、转发、讽刺和复杂多人语境可能错判；群标签仅是实验候选 |
| 画像显示「待判断」或样本不足 | 查看当前对象和已有有效文本范围，继续积累后再看 | 不强行给样本不足的人确定 MBTI，聊天画像不是标准心理量表 |
| 搜索或统计与 QQ 里看到的不一致 | 查看已读取范围、时间和缺口，确认同一会话和成员 | 有界读取与已读计数不代表 QQ 全历史，也不保证全部漫游记录 |
| CPU 分析需要等待 | 先浏览消息，留意分析状态；需要时暂停后继续 | 速度取决于设备，没有经跨机验证的统一最低内存与耗时保证 |
| GPU 无法使用或不稳定 | 切回 CPU；反馈显卡型号、驱动版本和错误提示 | 使用 WebGPU，仅开发机 Intel UHD 有实测，NVIDIA/AMD 等待测 |
| 更新后界面还是深色 | 在设置「主题外观」中选择「浅色模式」 | 新用户默认浅色，已保存的旧主题不会被强制覆盖 |
| 新解压目录没有旧消息 | 保留旧目录，从旧版导出备份，在新版恢复 | 每个便携目录独立，不会自动读取旧程序或开发目录的数据 |
| 换电脑后 Key/token 不可用 | 重新填写自己电脑上的凭证并确认连接 | Windows 账号保护的凭证不能当作通用跨机配置 |

## 分析结果应该怎样理解

标签与画像属于模型推测，可能错。标签百分比是模型输出分数，不是经过校准的准确率。群成员画像只代表这个人在当前群的已读发言，不是他的完整性格，也不合并其他成员或其他群。

目前仅有部分群语义例经人工接受为**明确标注的实验候选**，其余标签及画像仍需人工审阅。没有「全部模型质量通过」的结论。请不要仅凭标签给同学、朋友或群成员下定论。

## 还在验证的环境

**本机已验证，跨机正在测试。** 真实 API/Ollama、Windows 10、非开发者首次安装、多显示器、NVIDIA/AMD 等环境，以及完整语义和画像质量，尚没有完整通过结果。相关入口与功能保留，新的实测结果将继续更新。

本机假服务检查只证明 API 界面和流程，不证明真实服务能完成标签或画像。没有真实服务条件时，应记录为「没试」，不要写为成功。

## 更新与数据

当前采用手动更新，自动应用更新关闭；QQVibe 不使用 WechatVibe 的程序更新源。更新前先[备份并保留旧目录](BACKUP-UPGRADE.md)。

标准包需要自己获取模型；完整包已保留固定模型来源与许可，见[模型来源和许可](MODEL-LICENSE.md)。QQ 和 QCE 是另外安装的外部程序，升级它们后请先核对账号与连接状态。

如果发现启动失败、丢失数据、本人身份错误，或单聊/群成员之间出现串数据，请停止继续分析，保留原目录与提示，优先反馈。这类问题需要先处理，不能靠重装或删除数据掩盖。
