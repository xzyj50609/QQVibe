# 句豆 · ChatBean 第一次试用清单

这份清单可以直接复制给提供软件的同学。按[首次使用说明](SETUP.md)在自己的电脑操作，不需要安装开发工具。每项只填写 **正常 / 遇到问题 / 没试**；没有条件就写「没试」，不用为了填满清单购买服务或设备。

## 先填这几项

- 试用日期：
- QQVibe 版本（设置 → 关于 QQVibe）：
- 下载的 ZIP 文件名：
- Windows 版本（如 Windows 11）：
- QCE 版本（不知道可写「未知」）：
- 模型选择：本地 Laya / CPU，或其他：
- 是否第一次在这台电脑使用：是 / 否：

**不用写自己的 QQ 号码、群号、密码、token 或 Key。**

## 跟着做并记录

| 序号 | 请做这一步 | 应该看到什么 | 结果与补充 |
| --- | --- | --- | --- |
| 1 | 下载完整包，全部解压，打开 win-unpacked 中的 QQVibe.exe | 不安装开发工具也能打开 QQVibe，新用户默认浅色 | |
| 2 | 点「首次设置：连接 QQ、选择模型与会话」 | 可进入设置，模型和 QQ 连接入口能操作 | |
| 3 | 按说明安装 QCE，用自己的 QQ 登录；回 QQVibe 点「连接本机 QQ / QCE」 | 可连接，显示的是自己的身份 | |
| 4 | 选择「本地部署」「CPU」 | 模型就绪，没有要求再次下载完整包内的模型 | |
| 5 | 添加一个自己选择的单聊并打开 | 对方、我的身份和消息归属正确，只显示这段聊天 | |
| 6 | 查看「情绪 / 意图」和「人物画像」中的「我」「对方」 | 结果出现或清楚提示正在分析/样本不足，两个人不会混在一起 | |
| 7 | 添加一个有权查看的群聊并打开 | 群名、发言人和群名片正确，不混入其他聊天 | |
| 8 | 查看「群概览」，再点「选择成员」 | 计数对应已读范围，成员与画像对象一致，实验提示能看懂 | |
| 9 | 在「聊天记录」搜索一个自己记得的关键词 | 找到已读范围内的记录，并能看到上下文 | |
| 10 | QQ 正常收到或发送一条新文字时，观察 QQVibe | 新消息归属正确，可以继续出现分析结果，记大约等了多久 | |
| 11 | 正常退出 QQVibe，再从同一目录打开 | 会话、已有消息、结果与设置仍在，不串账号或群成员 | |
| 12 | 设置 → 关于 QQVibe →「导出诊断信息」 | 可以导出匿名诊断，不需要上传聊天或凭证 | |

第 6、8 项出现模型结果只表示功能运行；**标签是否合理另写自己的观察**，不要把它当成模型质量已经通过。觉得不合理时可写「把引用误当成本人说话」「标签不符合上下文」等问题类型，不必贴真实聊天。

## 有条件再做

| 可选项目 | 记录内容 |
| --- | --- |
| 备份并在新解压目录恢复 | 按[备份说明](BACKUP-UPGRADE.md)操作，核对会话与结果，保留旧目录与原备份 |
| 暂停、继续、取消分析 | 记录是否能继续阅读、已保存结果是否保留 |
| 两个显示器之间拖动 | 记录显示比例和控件是否异常，没有第二块屏幕就写「没试」 |
| 自己已有真实 API 或 Ollama | 分别记服务名、模型、协议与标签/画像结果，不填 Key，不用假服务代替 |
| 无模型标准包 | 记录缺模型提示、下载/选择目录和无需 Laya 进入 API 设置是否顺畅 |

## 把问题发回来

填写[反馈模板](FEEDBACK.md)，或直接发一句：

> 我用 QQVibe ___ 版，在第 ___ 步遇到问题。预期是 ___，实际看到 ___。错误提示是 ___。我使用 Windows ___、QCE ___、模型 ___。附匿名诊断。

可以发给提供软件的同学；会使用 GitHub 的人也可到 [Issues](https://github.com/xzyj50609/QQVibe/issues)提交。截图先遮盖账号、头像、昵称、群名和正文；**不上传聊天记录、数据库、完整备份或凭证**。

启动失败、数据丢失、本人身份或成员归属错误请优先报告，并保留原目录。其他问题也按真实情况写，不需要通过重装把现象藏起来。
