# R9 另一台电脑与非开发者试用清单

使用同一候选 ZIP、无开发环境的 Windows x64 电脑。开发者不得替试用者改源码或隐藏配置。先按 SETUP 准备本人 QQ/QCE 与选定模型；没有真实服务时该项记「未测」，不填通过。

记录包名、SHA256、candidate、系统/QQ/QCE/模型版本、内存/显卡/缩放/显示器数量、试用日期。结果只能填写「通过 / 失败 / 未测」，失败附实际步骤和脱敏提示，未测说明条件；耗时按实际秒数记录。测试库和反馈不公开真实聊天。
