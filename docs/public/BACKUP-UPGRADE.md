# 备份、升级与回退

便携程序的数据是本次解压目录的 `win-unpacked/resources/client/QQVibeData`，不会读取个人开发工程作为备用来源。每个解压目录独立；不要误用验收副本。

首次走通和换版前，在设置 →「完整数据备份与恢复」创建备份，保留 ZIP 及其 SHA256。备份含账号、聊天、分析及当前 Windows 账号保护的凭证，是私人资料，不附入公开反馈。

升级：先关闭旧版，保留旧目录及数据；新版解压到另一个可写目录，打开新版，从设置选择原备份并核对范围后确认恢复。程序退出后执行目录交换并重开；检查账号、会话、消息数量、结果与进度，再明确重新连接。不要覆盖运行中的文件，也不要把源码 ZIP 当升级程序。

若新版失败：关闭新版，直接打开旧目录程序；必要时在旧版通过设置恢复原备份。恢复失败保留原数据及回退目录，不手动删除失败现场。只有确认新版本数据和行为正确后，再决定保管旧版时长。

同一 Windows 账号的凭证受 DPAPI 保护；换机器/Windows 账号后重新填写 QCE token/API Key。备份恢复后不会擅自重新连接。跨机恢复仍需 R9 实测。运行时下载的模型位于数据目录下 `models/laya`；自选外部模型目录需独立保留，恢复备份不等于复制外部权重。
