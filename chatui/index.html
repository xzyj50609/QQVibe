QQ 连接与自动同步

先打开 QQ Chat Exporter 并登录 QQ，再点连接。仅此操作读取标准安装的受控配置，并在本机加密保存凭证；添加单聊后首次读取最近 90 天、最多 200 条消息，随后同步新消息。自定义安装使用下方高级设置。

导入聊天 JSON

支持 QCE、消息数组、嵌套消息列表和 JSONL。大文件分批读取，先核对内容与 QQ 身份，再写入本地历史。

识别不准确？指定字段与会话

留空自动识别。字段可写 sender.uin、content.text；消息列表位置可写 /data/messages，顶层数组填 /。缺少字段时不会编造。

只有昵称时，需要填写对应 QQ 号才能归属到人物；修改后再次点「预览」。一次选择一个会话的消息列表。
